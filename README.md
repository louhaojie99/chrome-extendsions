# Chrome Extensions

> 简易整理的 Chrome 扩展程序开发相关知识，方便日后记忆查阅。

## 项目清单

| # | 插件名称 | 插件描述 |
| --- | --- | --- |
| 1 | [hello_extensions](./hello_extensions) | 构建的第一个拓展程序 |
| 2 | [reading-time](./reading-time) | 显示文章预计阅读时间 |
| 3 | [focus-mode](./focus-mode) | 为 Chrome 官方文档提供专注阅读模式 |
| 4 | [tabs-manager](./tabs-manager) | 管理并分组 Chrome 官方文档标签页 |
| 5 | [quick-api-referenc](./quick-api-referenc) | 通过地址栏快速打开 Chrome API 文档 |
